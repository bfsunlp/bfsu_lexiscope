# BFSU ClearLens v1.4.2

## 累积处理状态

- 规则整理、直接大模型整理、大模型自然语言规则、大模型校对、转码准备和人工编辑统一以当前工作文本为输入。
- 大模型处理后继续执行规则整理时，规则作用于大模型结果，不再回退到导入原文；任意后续处理均按同一原则依次叠加。
- 文件状态新增明确的工作文本、未保存标记、目标编码和输出后缀模式，失败状态也不会使当前结果回退到原文。
- 撤回、重做和恢复原文会完整恢复文本、目标编码、保存状态与输出路径。

## 显式保存边界

- 选择输出目录只配置目标位置，不触发写出。
- 规则、大模型、校对建议与转码操作只更新内存结果；仅“保存”“另存为”“全部保存”以及用户明确确认的合并命令写入磁盘。
- 转码命令改为先严格校验并登记目标编码，保存时才执行实际编码输出。
- 文件队列显示未保存状态，处理日志明确记录“尚未保存”，处理完成状态不再声称已自动输出。

## v1.4.0 基础能力

### 大模型自然语言规则

- 左侧增加大模型规则面板，可新增、编辑、删除、启停和批量勾选自然语言整理需求。
- 多条启用规则在一次请求中共同处理。安全自动模式仍执行精确片段与无损校验；校对模式允许更广的建议，但必须逐条人工应用。
- 大模型规则保存在本机独立 JSON 文件中，并随整理方案导入导出；API 密钥仍会被递归剔除。

### 大模型生成正则

- 正则规则库增加“由大模型生成”，用户可输入自然语言需求并明确选择某个已导入文件作为样本。
- OpenAI 和 DeepSeek 均返回结构化 Python `re` 规则；程序先编译并试运行校验，再打开人工编辑窗口确认。
- 未选样本时只发送需求；选定样本时遵循发送前确认设置。

### 操作历史与保存提示

- 编辑菜单增加撤回、重做、当前恢复原文、选中恢复原文和全部恢复原文。
- 最近 50 项文本操作统一记录，覆盖人工编辑、单文件处理、多文件批处理和大模型建议应用；一次批处理作为一个历史项。
- 全部保存和各类处理任务完成后均显示相应状态提示。
- 移除全部文件拆分入口、对话框、实现代码和测试。

## v1.3.0 基础能力

### 操作效率

- 每个可勾选功能面板增加“全选”和“取消全选”，一次完成同组规则切换。
- 工具栏增加当前文件/全部文件字符数摘要，并提供当前、选中和全部文件的详细统计窗口。
- 工具栏、快捷键和设置窗口均可调整编辑器字号。
- 用户可将当前整理参数和自定义正则保存为独立 JSON 方案，也可导入方案复用；方案会自动剔除全部 API 密钥。
- 设置窗口增加“恢复默认设置”，恢复时保留当前输入的密钥，避免意外丢失。

### 大模型与隐私

- 增加 OpenAI / ChatGPT 与 DeepSeek 双服务商选择、独立模型和独立密钥配置。
- 两类密钥均可单独清除，可选择仅在当前会话使用或保存在本机用户设置中。
- DeepSeek 采用 JSON 输出并复用原有精确定位、无损校验、重叠拒绝和人工逐条确认机制。
- 界面术语统一为 LLM / 大模型。

### 文本整理

- 增加去除 Emoji 表情符号。
- 增加去除 JavaScript、CSS、`noscript`、`template` 等网页代码块，包含 HTML 实体还原后的转义代码块。
- “去除所有空行”现在识别 `&nbsp;`、`<br>`、HTML 注释、空标签和嵌套空标签；已使用四份真实网页附件回归。

### 文档

- “关于”补充完整功能边界、人机协同方式、密钥与文本发送规则和免责声明。
- 作者信息更新为刘鼎甲博士 / Dr. Liu Dingjia，邮箱 `djliu@bfsu.edu.cn`。

## v1.2.0 基础能力

### 任务与性能

- 修复多文件导入后因文件树选择事件与预览互相触发而导致的界面卡死。
- 文件发现、读取、规则整理、转码、保存和合并均在界面线程之外执行。
- 增加任务进度条和“中止任务”；中止后立即恢复界面，并丢弃延迟返回结果。
- 增加并行批处理设置。本地规则整理可使用多进程，默认任务数为逻辑处理器数量的一半。
- 大文件预览支持字符上限；截断只影响预览，不影响完整处理和输出。

### 文件与编码

- 增加保存、另存为、全部保存，并从文件菜单、工具栏和右键菜单访问。
- 输出目录不能与导入文件所在目录相同，写出层也禁止目标路径覆盖任何源文件。
- 增加当前、选中和全部文件转码，支持 UTF-8、UTF-16、UTF-32、GB18030、GBK、Big5、Shift-JIS、CP949、CP1252、Latin-1 和 ASCII。
- 增加合并选中和合并全部。

### 整理与界面

- 基础规范化增加“清除行首空白”。
- 所有可见的旧有模型术语统一为 LLM/大模型。
- 左侧输出区可直接选择目标编码，并移除重复分组。

### 安全性

- 大模型直接整理仍只接收通过程序校验的空白、段落、标点、完全重复与纯符号编辑。
- 词汇和语义性建议仍必须在独立校对窗口逐条人工应用。
